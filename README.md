# sephora-review-analysis
丝芙兰评论分析及面部防晒产品定位
## 数据来源与整合

### 1. 评论数据合并

合并5份评论文件，得到 **1,094,411条评论、19个字段**，并转换为Parquet格式，便于后续读取与分析。

评论表以单条评论为单位，包含以下字段：

| 字段 | 含义 |
|---|---|
| `Unnamed: 0` | 原始文件导出的行索引，非业务字段 |
| `author_id` | 评论者ID |
| `rating` | 单条评论的星级评分 |
| `is_recommended` | 是否推荐，通常1为推荐、0为不推荐 |
| `helpfulness` | 评论有用度指标 |
| `total_feedback_count` | 评论收到的反馈总数 |
| `total_neg_feedback_count` | 认为评论无帮助的反馈数，不代表商品差评数 |
| `total_pos_feedback_count` | 认为评论有帮助的反馈数 |
| `submission_time` | 评论提交日期 |
| `review_text` | 评论正文 |
| `review_title` | 评论标题 |
| `skin_tone` | 评论者肤色 |
| `eye_color` | 评论者眼睛颜色 |
| `skin_type` | 评论者肤质 |
| `hair_color` | 评论者发色 |
| `product_id` | 商品ID，用于关联商品表 |
| `product_name` | 商品名称 |
| `brand_name` | 品牌名称 |
| `price_usd` | 商品美元价格，不代表用户实际购买价格 |

### 2. 商品信息整理

商品表包含 **8,494条商品记录、27个字段**，用于补充商品的品牌、品类、规格及销售属性。

以下列出主要字段：

| 字段 | 含义 |
|---|---|
| `product_id` | 商品ID |
| `product_name` | 商品名称 |
| `brand_id` | 品牌ID |
| `brand_name` | 品牌名称 |
| `loves_count` | 商品收藏／喜爱数量，不等同于销量 |
| `rating` | 商品层面的汇总评分 |
| `reviews` | 商品表记录的评论总量 |
| `size` | 商品容量或重量规格 |
| `variation_type` | 变体类型，如容量、色号或配方 |
| `variation_value` | 具体变体信息 |
| `online_only` | 是否仅在线销售 |
| `out_of_stock` | 数据采集时是否缺货 |
| `sephora_exclusive` | 是否为丝芙兰独家商品 |
| `highlights` | 商品特点及卖点标签 |
| `primary_category` | 一级品类 |
| `secondary_category` | 二级品类 |
| `tertiary_category` | 三级品类 |
| `child_count` | 关联子变体数量 |
| `child_max_price` | 关联子变体的最高价格 |
| `child_min_price` | 关联子变体的最低价格 |

### 3. 评论与商品信息关联

以 `product_id` 为关联键，将评论记录与商品属性整合，得到 **1,094,411行、30列**的分析明细表。

合并表以评论为分析单位，将信息整合为三个层面：

| 信息层面 | 主要内容 | 分析用途 |
|---|---|---|
| 用户评价 | 评分、推荐情况、评论文本及日期 | 识别用户需求、痛点及评价变化 |
| 用户特征 | 肤质、肤色等 | 比较不同人群的使用反馈 |
| 商品属性 | 品牌、价格、品类及商品特点 | 开展品类筛选、竞品对比与产品定位分析 |

通过关联，可将单条评论中的使用体验对应到具体产品、品牌及细分品类，为后续“品类筛选—痛点识别—人群差异—竞品对比”提供数据基础。

**口径说明：**

- 评论表的 `rating` 是单条评论评分，商品表的 `rating` 是商品汇总评分，分析时需区分。
- 商品表的评论总量与本项目实际收集的评论条数可能不同。
- 合并前后总行数未变化，不代表所有评论均成功匹配，仍需检查商品ID唯一性及关联缺失情况。
